# AI-Assisted Advertisement Generator

This repository is being initialized. The complete runnable project bundle is available in the conversation download: `ai_assisted_digital_advertisement_generator.zip`.

It contains a Python + Pillow rule-based ad generator, a Streamlit interface, examples, tests, and a Google Colab notebook.

## Run locally

```bash
python -m pip install -r requirements.txt
streamlit run app.py
```

The current generator is an offline rule-based prototype; it does not call an LLM or image-generation API.
